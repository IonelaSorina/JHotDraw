# SB5-MAI Software Maintenance — Exam Aids

Personal exam aid package for the 15-20 page essay exam.
Lectures, labs, and the portfolio distilled into a searchable reference library.

> **Use rule:** during the exam, open the aid you need *first*, write directly from it. Don't re-read the portfolio under time pressure — it's 3,900 lines. These aids are the *index* into it.

## Recommended exam-day workflow

**Minute 0 – 10: Read the question. Open file 01.**
- Identify the question type (descriptive / analytical / comparative / evaluative).
- Pick the template that matches.
- Draft a 1-sentence thesis on paper.

**Minute 10 – 30: Open file 03. Find the closest question.**
- If the question resembles one of the 30+ in the bank, copy its outline.
- If not, find 2-3 questions whose outlines you can *combine*.
- Write a sketch outline (5-7 main sections).

**Minute 30 – 60: Open files 02, 04, 05, 06.**
- For each main section, pull 2-3 pieces of evidence: a quote (04), a number (06), a code pattern (05), and the lecture's argument (02).
- Annotate your outline with these references.

**Minute 60+: Write.**
- Use file 01's transition phrases as connective tissue.
- Use file 07 if you blank on a term.
- Use file 08 to confirm that the section transitions are *load-bearing* (each section should follow from the previous, not just sit next to it).

## What the aids do NOT contain

- **Your actual portfolio** — that's [portfolio/portfolio.md](../portfolio/portfolio.md). Keep it open in a separate tab; the aids point into it.
- **The full lecture slides** — distilled to arguments, not reproduced verbatim. If a slide image is critical, the aids cite the slide number and you go look.
- **AI / external sources** — you cannot use these in the exam. Everything in these aids is derived from your own course material.

---

## How to read this package as a *whole*

If you read every file end-to-end before the exam (~3-4 hours), you will:

1. Have a working essay template memorised (file 01).
2. Recognise every lecture / lab argument when you see it in the question (file 02).
3. Know which quote and which number belong with which argument (files 04, 06).
4. Know what concrete example from your own work to drop in for *every* claim (files 03, 05).
5. Have an internal concept map linking topics that makes a 15-20 page essay *feel coherent* rather than a list of paragraphs (file 08).

That is the goal. Good luck.
